# Sepsis immunometabolic failure endotype (KLRF1+ NK-cell readout)

Analysis scripts for the manuscript:

**"An Immunometabolic Failure Endotype in Sepsis Is Characterized by Depletion of KLRF1-Expressing NK Cells"**
Kun He et al. (under review)

This repository contains the R scripts used to define and validate an
immunometabolic failure endotype (Q1) in sepsis using a two-axis
(immune score x metabolic score) quadrant classification, to anchor the
endotype to a KLRF1+ high-fitness NK-cell mechanism, and to run the
pneumonia-adjusted sensitivity analyses that establish clinical
independence of the Q1 mortality signal.

## Data sources (all public)

| Cohort | Accession | Use |
|---|---|---|
| GSE65682 | GEO, n=479 | Discovery: quadrant classification, survival, pneumonia sensitivity |
| GSE13904 | GEO, n=260 | External: sepsis vs control discrimination |
| GSE95233 | GEO, n=124 | External validation (survival) |
| GSE54514 | GEO, n=35 | External validation (Day-1 sepsis) |
| E-MTAB-4421 | ArrayExpress | External validation |
| GSE167363 | GEO | Single-cell validation (NK cells, KLRF1) |

Expression matrices are available from NCBI GEO / ArrayExpress under the
accessions above. Processed score files (e.g. `scores_GSE65682.rds`) are
generated by the scoring pipeline in `scripts/` and are not redistributed
here (raw data are public).

## Scripts

| Script | Purpose |
|---|---|
| `scripts/pneumonia_sensitivity.R` | Pneumonia-adjusted Cox sensitivity analysis (GSE65682, n=479); Q1 vs Q2-Q4 with none/CAP/HAP covariates |
| `scripts/supp_table_S7_pneumonia.R` | Pneumonia x quadrant contingency table (Supplementary Table S7) |
| `scripts/fig1d_forest.R` | Fig. 1d multivariable Cox forest plot |
| `scripts/figures_fill.R` | Main figure panels (Fig 1a-c, 3b, 5a-c) |
| `scripts/stitch_klrf1_quadrant.R` | KLRF1 quadrant analysis (Fig 3a) |
| `scripts/scRNA_klrf1_nk.R` | Single-cell KLRF1+ NK analysis (Fig 2c, 4) |
| `scripts/fig3c_umap.R` | scRNA UMAP / cell-type annotation (Fig 2b, 3c) |
| `scripts/immune_landscape_quadrant.R` | Immune landscape heatmap (Fig 2a) |

Key outputs (pneumonia sensitivity):

- Q1 vs Q2-Q4, age+sex adjusted: HR 1.82 [1.25-2.65], p = 0.0018
- Q1 vs Q2-Q4, + pneumonia status: HR 1.87 [1.28-2.73], p = 0.0011
- Pneumonia itself vs mortality: HR 0.76 [0.51-1.11], p = 0.16
- Pneumonia by quadrant: Q1 42.7%, Q2 24.8%, Q3 46.8%, Q4 37.7% (Fisher p = 0.004)

## Requirements

- R >= 4.1 (survival, pheatmap, Seurat for single-cell scripts)
- RDS inputs generated from GEO series matrices (see scripts for column
  expectations)
